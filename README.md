# 夸克中转站 · QuarkRelay

把「别人的网盘链接」变成「你自己的分享链接」。

**当前版本：v1.1.1** · Windows 10/11 · 单文件 exe，免安装

---

## 这是什么

你复制了一段别人分享的夸克链接 —— 里面往往还夹着提取码、几句介绍、甚至一张二维码。
QuarkRelay 要做的事情很简单：

1. **认出链接**（粘贴 / 剪贴板 / 截图 / 二维码都行）
2. **转存到你的夸克网盘指定目录**
3. **生成一条属于你的分享链接，并带上你起的名字**
4. 最后给你一段可以直接贴出去的文本：`名字 + 链接`

除此之外，它还能在**百度网盘和夸克网盘之间双向搬运** ——
整个过程用的都是程序**内置的浏览器会话**，不会动你系统浏览器里的登录状态，
下载数据也**不会落到桌面上**。新版本还会**自己去 GitHub 上检查更新并一键自动更新**。

## 四个核心能力

### 一、夸克中转（转存 + 生成分享）

* 粘贴区支持「一坨文字」，自动识别里面的夸克分享链接与提取码
* 支持一次粘贴多条，批量转存、批量生成分享
* 转存目录可以填多级路径（`中转站/2026-09`），不存在会自动创建
* 分享名字可自定义，留空则自动用分享标题／文件名
* 结果区支持「复制名字 / 复制链接 / 复制全部（名字+链接）」
* 生成结果按你的**命名模板**组合，模板支持 `{name}` `{link}` `{code}` `{index}` `{date}`

### 二、截图识链（页内小相机）

截图识链不是独立页面，而是页面右上角一个 **18px 的相机小图标**：
在「夸克中转」页识别夸克链接，在「跨盘搬运」页按当前方向识别百度或夸克链接，
识别结果直接填进该页的输入框。**左键点一下就是框选识别**，右键选更多方式。

* **框选识别**：全屏遮罩拖一个框，只识别框里的内容
* **整屏识别**：直接拍下当前屏幕（多显示器会拼接成一张）
* **打开图片**：识别本地图片文件
* **读剪贴板**：剪贴板里是图就识图，是文字就识文字
* 识别通道有两条，同时跑：
  * **Windows 系统 OCR**（Win10/11 自带，离线、不联网、不装模型）
  * **二维码解码**（OpenCV，多尺度 + 二值化，小二维码也能认）

### 三、跨盘搬运（百度 ↔ 夸克 双向）

顶部一个方向开关，两条链路都不落桌面：

* **百度 → 夸克**：粘贴百度分享链接与提取码，解析出文件列表（可勾选）→
  转存到自己百度网盘的中转目录 → 取直链、流式下载 → 上传夸克 → 可选生成夸克分享
* **夸克 → 百度**：粘贴夸克分享链接，预览内容（整包转存）→ 转存到夸克中转目录 →
  流式下载 → 上传百度网盘（同名自动加序号 / 跳过 / 覆盖）→ 可选生成百度分享

### 四、检查更新与一键自动更新

* 读取 GitHub 上的最新 Release，按数字段比对版本
* 显示新版本号、安装包大小、发布日期与该版本的更新公告
* 点「立即更新」→ 后台带进度下载 → 校验 → 退出后自动替换并重启，不用去网页下载
* 默认启动静默检查；发现新版本且没有任务在跑时会自动安装（有任务则推迟）

> **关于百度下载直链的技术说明**（重要，也是它为什么能长期可用）
>
> 百度网盘的下载直链由百度前端用**私有签名算法**生成。QuarkRelay 不做签名逆向，
> 而是采用另一条路：在**程序内置的浏览器**里打开百度网盘页面，让页面自己去请求下载，
> 程序从 QtWebEngine 的 `downloadRequested` 事件里**截获那条真实请求**，
> 再拿同一份会话 Cookie 在后台把它流式读下来。
>
> 好处是：不需要破解签名、不依赖第三方解析服务、签名失效也不会立刻挂掉；
> 而且下载全程走程序内部，不经过你的系统浏览器，也不落桌面。
>
> 如果自动点击下载按钮失败（百度前端改版了），程序会自动把浏览器窗口弹出来，
> 你手点一下「下载」即可，程序照样能截获直链。

## 登录是怎么做的（不会影响你平时上网）

* 两个网盘的登录**都在程序内置的浏览器窗口里完成**，支持扫码
* 登录窗口左边会把页面上那枚二维码**单独抠出来放大展示**（白底卡片 + 静区，好扫），
  它和右边网页里是同一枚，页面换码会自动跟着更新，也能手动点「刷新二维码」
* 使用 QtWebEngine 的**命名持久化 Profile**，Cookie 存在
  `%APPDATA%\QuarkRelay\webengine\` 下，和你的系统浏览器（Chrome/Edge）**完全隔离**
* 读取 Cookie 用的是 `QWebEngineCookieStore.loadAllCookies()`，能拿到
  `BDUSS` / `STOKEN` 这类 **HttpOnly** Cookie（这正是普通 JS 注入拿不到的部分）
* **夸克**走的是夸克网盘开放平台的**授权码流程**（OAuth），授权成功后只保存
  access_token / refresh_token，令牌过期会自动刷新
* 卸载／忘记密码都不影响：设置页有「清除全部登录凭据」一键清空

## 一些贴心的小地方

* **剪贴板监听**：复制到夸克链接，输入框自动填好
* **命名模板**：五种常用格式一键切换，实时预览
* **完成后自动复制**：分享生成后「名字 + 链接」已经躺在你的剪贴板里
* **全局快捷键**：默认 `Ctrl+Alt+Q`，在任何界面直接对当前页截图识链
* **系统托盘**：关闭窗口 = 最小化到托盘，任务继续跑（可在设置里改成关窗即退出）
* **并发与限速**：同时跑几个任务、下载限速多少，都能调
* **秒传优先**：上传夸克／百度前都会先试官方秒传，命中就直接完成，不浪费流量
* **多分片上传**：大文件按官方分片上传（百度 4MB / 夸克按 `part_size`），进度条实时可见
* **深浅色主题**：两套配色，都是自己调的，不是套模板
* **自动更新**：启动静默检查 GitHub Release，可一键下载、自动替换重启

## 安装与运行

### 方式一：下载 exe（推荐）

去 [Releases](https://github.com/zlwzk/QuarkRelay/releases/latest) 下载
`QuarkRelay.exe`，双击就能用，不需要装 Python 或任何运行库。

### 方式二：从源码跑

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

要求 Python 3.10+（推荐 3.11 ~ 3.13）。

### 打包 exe

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

脚本会依次：生成内置文档 → 跑自检 → 生成图标 → PyInstaller 单文件打包 →
**启动 exe 做一次离屏自检**（装配界面 + 真正渲染一个网页，确认内置浏览器在打包后还能用），
产物在 `dist\QuarkRelay.exe`。

想单独验证手上的 exe 是否完好，可以直接跑：

```powershell
.\dist\QuarkRelay.exe --check      # 结果写到 %TEMP%\quarkrelay-selfcheck.json
.\dist\QuarkRelay.exe --version
```

## 数据存在哪

全部在你自己的电脑上，都在 `%APPDATA%\QuarkRelay\` 下：

| 文件 | 内容 |
| --- | --- |
| `config.json` | 设置 + 登录令牌 / Cookie |
| `history.db` | 历史记录（SQLite） |
| `webengine\` | 内置浏览器的浏览器数据 |
| `logs\` | 运行日志 |
| `cache\buffer\` | 搬运时的临时下载缓冲（完成后自动删除） |
| `update\` | 自动更新时下载的新版 exe 与替换脚本 |

设置页里可以一键打开这个目录，也可以一键清除全部登录凭据。

## 已知限制

* 百度 → 夸克这条链路依赖百度网盘网页版的结构；如果百度改版导致自动点击失败，
  程序会弹出浏览器窗口让你手点一下「下载」，其余全自动
* 百度分享里的**目录**暂不支持整目录搬运，请勾选具体文件
* 夸克 → 百度方向是**整包转存**（暂不支持在夸克分享里勾选），搬运前可在预览里确认内容
* 自动替换依赖程序目录可写；装在 `Program Files` 这类需要管理员权限的目录时会降级为手动下载
* 截图 OCR 用的是系统引擎，需要 Windows「中文(简体)」语言包（中文 Windows 默认就有）
* 非夸克分享链接的转存暂不支持（阿里云盘 / 123 云盘 / 天翼等已在链接识别里做好分类，
  后续版本会陆续接通）

## 使用的技术

* Python 3 + PySide6（Qt 6 Widgets + QtWebEngine）
* 夸克网盘开放平台 HTTP API（OAuth + SHA256 请求签名）
* 百度网盘网页版接口（会话 Cookie + bdstoken）
* Windows.Media.Ocr（系统 OCR）+ OpenCV QRCodeDetector
* SQLite（历史记录）
* PyInstaller（打包单文件 exe）
